Привітання для вхідних

MP3-файл, який чує абонент після автопідняття, перед з'єднанням із живим звуком інтеркому. Файл конвертується у формат дзвінка автоматично.

Запис розмов

Записується лише з'єднана частина розмови (MP3). Зберігаються записи для останніх 50 дзвінків; «Очистити» в журналі видаляє і записи. Дотримуйтесь вимог законодавства щодо згоди на запис.

Аудіо

I2S HAT конфігурується як пристрій ALSA за замовчуванням у setup-скрипті. Значення нижче — для тонкого налаштування.

Список — виявлені звукові пристрої. «Системний за замовчуванням» лишає вибір за ОС. Обери свою USB-картку (напр. H1n). Потрібен перезапуск (застосується автоматично).

Кнопка та індикація (GPIO, BCM)

I2S використовує GPIO 18–21 — не використовуйте їх для кнопки/LED.
