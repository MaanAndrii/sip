# Технічне завдання — SIP-інтерком на Raspberry Pi Zero 2 W

Узгоджена версія (використовується як основа реалізації).

## 1. Призначення
Легкий автономний SIP-клієнт (аудіо-інтерком) на Raspberry Pi з керуванням
однією фізичною кнопкою та повним налаштуванням через веб-інтерфейс.

## 2. Апаратна платформа
- **Основні:** Raspberry Pi 4 та Raspberry Pi 5.
- **Підтримувана:** Raspberry Pi Zero 2 W.
- ОС: Raspberry Pi OS (Debian bookworm, 64-bit).
- **Аудіо:** USB-звукова карта (мікрофон + динамік) — рекомендовано, працює на
  всіх платах. Альтернатива — I2S HAT (ЦАП + мікрофон) на GPIO 18–21.
  Примітки: Pi 5 не має аналогового аудіо-джека; Pi 4 має лише вихід (без
  мікрофонного входу); Zero 2 W не має вбудованого аудіо.
- **Мережа:** Ethernet (Pi 4/5) або WiFi; на логіку не впливає.
- **Кнопка:** GPIO17 (BCM), до землі, внутрішній pull-up.
- **LED статусу:** GPIO27 (BCM), опційно.
- GPIO однаковий на всіх платах (40-pin). На Pi 5 (чип RP1) використовується
  pin-фабрика `lgpio`.

## 3. SIP
- Одночасна реєстрація на **1–3 акаунтах**; усі тримаються активними.
- Кодеки: **G.711 (PCMU/PCMA)**.
- Транспорт (на акаунт): **UDP / TCP / TLS**; звичайний SIP-провайдер
  (Asterisk/FreePBX/хмарний).
- **Шифрування (на акаунт):** сигналізація — TLS; медіа — **SRTP** (SDES),
  опційне або обов'язкове. Потрібно для клієнтів, що очікують шифрування
  (напр. Linphone). У самому Linphone-додатку тип шифрування медіа має бути
  **SRTP**.
- Тільки аудіо (без відео).
- SIP-рушій: **PJSIP / PJSUA2** (Python).

## 4. Вихідні виклики (кнопка)
- Один **глобальний список** цільових номерів, упорядкований за пріоритетом.
- **Кожен номер прив'язаний до свого SIP-акаунта** (з нього й здійснюється виклик).
- Натискання кнопки в стані очікування → послідовний обхід:
  дзвонимо на №1; якщо **не відповіли за 15 с**, або **зайнято**, або
  **відхилено** → одразу переходимо до наступного за пріоритетом.
- При відповіді послідовність зупиняється — йде розмова.
- Якщо ніхто не відповів — повернення в очікування.

## 5. Кнопка (одна, контекстна)
| Стан пристрою      | Дія кнопки                        |
|--------------------|-----------------------------------|
| Очікування         | Старт послідовного набору         |
| Набір              | Скасувати набір (відбій)          |
| Розмова            | Завершити виклик                  |
| Вхідний дзвінок     | Відхилити / завершити             |

Утримання не використовується.

## 6. Вхідні виклики
- **Автовідповідь** на дзвінки з будь-якого номера **після 2 гудків**
  (≈6 с затримки, налаштовується).
- Якщо на момент вхідного вже виконується **вихідний виклик/набір** — вхідний
  **відхиляється як «зайнято» (486 Busy Here)**.

## 7. Веб-інтерфейс
- Уся конфігурація (акаунти, номери, таймаути, вхідні, аудіо, GPIO).
- **Авторизація логін/пароль**, за замовчуванням **admin/admin**;
  пароль змінюється в інтерфейсі (зберігається у вигляді PBKDF2-хешу).
- Жива індикація стану (стан пристрою, активний виклик, реєстрація акаунтів)
  через Server-Sent Events.
- **Журнал викликів** — останні 50 вихідних і вхідних дзвінків (час, напрям,
  номер, акаунт, результат: відповіли/не відповіли/зайнято/відхилено/скасовано,
  тривалість). Зберігається на диск, переживає перезапуск.
- **Автоматичний перезапуск служби** при збереженні налаштувань, які цього
  потребують (акаунти, кодеки, аудіо, GPIO, порт веб) — застосовуються без
  ручного втручання. Налаштування набору/вхідних застосовуються «на льоту».
- **Привітання для вхідних:** завантажений MP3 програється абоненту після
  автопідняття, перед підмиканням живого звуку («відповісти + програти +
  підмкнути»). Конвертація MP3→WAV через ffmpeg.
- **Автоматичний запис розмов** (опційно, дефолт вимк.): записується з'єднана
  частина, зберігається у MP3 в `/var/lib/sip-intercom/recordings/` для останніх
  50 дзвінків, доступна для прослуховування/завантаження з журналу. «Очистити»
  видаляє й записи. Відповідність законодавству щодо згоди — на власнику.
- Доступ у локальній мережі (HTTP).

## 8. Системне
- Автозапуск через **systemd**; автоматичний рестарт при збої.
- Конфігурація у JSON (`/etc/sip-intercom/config.json`).
- Логи через journald.

## 9. Індикація (LED)
| Стан        | LED         |
|-------------|-------------|
| Очікування  | Вимкнено    |
| Набір       | Швидко блимає |
| Вхідний     | Повільно блимає |
| Розмова     | Світиться   |
